What is Semantic HTML?

Semantics in HTML focuses on the role and purpose of elements rather than their appearance. Semantic elements like <h1> provide meaning to content, helping browsers, screen readers, and search engines understand structure.

Benefits of Semantic Markup

  • Improves SEO by helping search engines index content effectively.
  • Enhances accessibility for screen readers and visually impaired users.
  • Makes code more maintainable by clearly defining content types.

Key Semantic Elements

Updated Nov 2023

<section> Element

Groups thematically related content, like chapters or news items.

<article> Element

Represents self-contained content such as blog posts or comments that can stand alone.
